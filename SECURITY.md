# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

The Valorex team takes the security of our browser, user privacy, and build supply chain seriously.

If you discover a security vulnerability within Valorex:

1. **GitHub Private Vulnerability Reporting:**
   Please report it privately through GitHub's [Security Advisory tab](https://github.com/seotarek/valorex/security/advisories/new).
2. **Direct Contact:**
   Alternatively, open a confidential issue or contact the maintainer directly via GitHub [@seotarek](https://github.com/seotarek).

### What to Include

Please provide:
- A clear description of the issue and potential security impact.
- Step-by-step reproduction steps or a minimal proof of concept (PoC).
- Your operating system, GTK version, and WebKitGTK version.

### Response & Disclosure

- We will acknowledge receipt of your report within 48 hours.
- We will coordinate a fix and release a security advisory with appropriate credit.
- We kindly ask you not to disclose the vulnerability publicly until a patch has been published.
